# Process Outline Approval

The main renderer is Round 1 Continuous Outline, refined in Variator and explicitly approved for integration. `approval.json` retains the exact revision, source hash, tokens, scoped decisions, and verification evidence. `original-source.txt` retains the pre-Apply renderer.

## Authoring

Write one named process with action children per block. Keep steps and supporting notes bite-sized and visible. Split independent processes into separate blocks. The `process-outline.single-parent` completion lint checks the structural requirement; it does not invent names or change runtime semantics.

## Scope

Depth colors, 1.5px connectors, and independently adjustable note text, dots, and vertical rules belong to Process Outline. State Shape and Interaction Surface layouts are not requirements here. The top-circle proposal is not part of the approved design.
