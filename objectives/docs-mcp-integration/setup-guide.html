Update and Stop

Check the installation or service:

bun packages/docs-mcp/src/cli.ts doctor
bun packages/docs-mcp/src/cli.ts status

After changing imported implementation code, close the shared workbench terminal, stop the service, and reconnect the clients. Then restart the workbench:

bun packages/docs-mcp/src/cli.ts stop
bun packages/docs-mcp/src/cli.ts ui --workspace .. --project docs-system --port 4808

The service restarts automatically on the next connection or UI command. Old task IDs and undo history do not survive a restart.

Refresh installed skills and save a new snapshot:

bun packages/docs-mcp/src/cli.ts install --write
bun packages/docs-mcp/src/cli.ts snapshot --out snapshot.json

Both existing config files have backups listed in the installation report. Preview a restore with:

bun packages/docs-mcp/src/cli.ts restore objectives/docs-mcp-integration/artifacts/install-result.json

The restore refuses files that changed after installation. Do not overwrite newer client settings with an old whole-file backup. Claude can update its own state file after a connection check; use its native MCP removal command if exact restoration refuses. No restoration is performed by this guide.
