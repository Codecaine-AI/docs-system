Variation A — Airy Structural

Process Outline restyled spacing-first. Rail geometry, elbow/arrowhead math, code chips and keyword bolding are the shipped baseline verbatim; what changes is air, indent, a single-hue rail ramp, a subordinated note card, and a minimal actor chip. Both panels below use the real semantic.css light and dark token values as their base.

Worker claims the job and its Epoch target atomically
Claim returns a ClaimToken — job id, kind, lease id
Task re-verifies the token; mismatch rejects the write
A stale process can never write on a claim it no longer holds. Every durable write — baseline score, session ids, widening, checkpoints — passes the token as authority.
Provision an isolated sandbox at the claim's base_rev
Seed from the game snapshot; fetch the delta by git bundle
The claim-time base_rev is authoritative for the whole job — a value re-read after a multi-minute provision could name a commit the sandbox never fetched.
Repeat: attempt, validate, checkpoint — until nothing is left to repair or the claim deadline passes
Agent attempts the packet; workspace diff is captured
Validation merges change check, post-return check, review lint
Next attempt receives the repair reasons verbatim
For each attempt, a checkpoint row banks the evidence
Gate the best checkpoint
Hard gate = runner validation passed and review lint not failed
Exact match closes the Worker exact; banked improvement closes timeout
Lease expires → job reaped, sandbox torn down, target returns to admitted
